# 中国航天探索馆

双击 `index.html` 即可打开完整展馆。字体、地球纹理和两个三维交互展区全部内嵌，运行无需联网。推荐使用开启图形加速的 Chrome 或 Edge。

三章顺序：**历史博物馆 → 天宫空间站 → 火箭与发射**。全站使用蓝黑底色、暖金强调色与统一章节导航。

## 历史博物馆

- 采用纯文字纵向时间线，20 个代表性节点按年代连续排在同一页，覆盖 1956—2025 年。直接向下滚动即可阅读。
- 每项保留日期、标题与简短成就介绍，分为四个历史阶段。目录可快速跳转。
- 杭州与浙江的四个节点单独强调：浙大皮星一号 A、皮星二号、浙江火箭动力试验能力和之江实验室三体计算星座。可直接定位杭州内容。
- 历史馆不展示图片、三维展品或轮播，阅读不需要逐项点击。切换模型章节再返回时保留历史馆的阅读位置。

## 交互

第二章保留电影式开场、实体/剖切/透视/爆炸、实验设施与生活区讲解、带碰撞检测的舱内漫游。舱内点击画面后可用 WASD 移动，Q/E 升降，拖动环视，Esc 释放鼠标；手机使用屏幕方向按钮。

第三章保留长征十号、昊龙、火箭拆解、内部剖视、发射分级、发动机与神舟返回舱展品。外部研制方案与教学动画不列为已完成的历史飞行成就。

隐藏模型章节停止申请动画帧并清除移动输入，恢复章节时继续操作。历史馆使用网页原生滚动，无 WebGL 场景。减少动态效果偏好下全文直接可见。

## 网页嵌入

把 `index.html` 上传到网站静态资源目录后即可使用：

```html
<iframe src="/aerospace/index.html"
        title="中国航天探索馆"
        style="width:100%;height:850px;border:0"
        allow="fullscreen; autoplay"></iframe>
```

`#museum`、`#station`、`#rocket` 可直接进入相应章节。外部史料链接需要联网。

## 修改与重新构建

在本目录执行：

```sh
npm install
npm run build
npm run preview
```

Node.js 20 或更高版本。也可使用已安装的本机 Teardown 依赖。`build.mjs` 读取父目录空间站离线页、`assets/launch.html` 火箭离线快照及本目录源码，生成单文件 `index.html`，并同步工作目录中的 `中国航天探索馆_三章合一.html`。离线成品不需要安装 Node.js。

`history.js` 管理事件。旧照片版的 `photos.json` 与 `assets/photos/` 仅作为素材档案保留，当前纯文字历史馆不加载或打包这些图片。

## 验证与资料

`npm run verify` 验证离线运行、20 项纯文字历史、真实滚轮下拉、目录定位、阅读位置恢复、空间站交互、火箭子展品、隐藏章节暂停及 320 / 390 / 768 / 1600 像素宽度。先执行 `npx playwright install chromium`，或通过 `CHROME_PATH` 指定现有 Chrome。

`validation.json` 为交互报告，`source-validation.json` 为史料链接核对报告，`captures/` 为验收截图。`check-sources.mjs` 可重新检查史料可访问性；HTTP 成功本身不代替人工核对内容。

`照片与史料记录.md` 保留旧照片版的对应关系及当前模型边界；软件与字体许可在 `licenses/`。旧图片档案的权属以 `photos.json` 记录为准。
