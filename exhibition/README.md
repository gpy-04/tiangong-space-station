# 中国航天探索馆

双击 `index.html` 即可打开完整展馆。图片、三维代码、字体、地球纹理和两个交互展区全部内嵌，运行无需联网。推荐使用开启图形加速的 Chrome 或 Edge。

三章顺序：**历史博物馆 → 天宫空间站 → 火箭与发射**。全站使用蓝黑底色、暖金强调色与统一章节导航。

## 历史博物馆

- 默认进入“杭州与浙江”，选取浙大皮星一号 A、皮星二号、浙江火箭动力试验能力和之江实验室三体计算星座四项成就。
- 可切换全国成就时间线、起步与突破、载人航天、月球与深空、服务与探索、空间站时代；共 20 个代表性节点，覆盖 1956—2025 年。
- 每项默认显示日期、标题、一句重点与关键数据。详细历史和原理放在“展开讲解”中。
- 20 项均配有真实照片或航天器实拍，支持放大查看。图注说明拍摄对象，主界面不显示图片出处。不同年代的相关实物展陈、工程配套和后续任务影像均写明对象，不冒充事件当日照片。
- “历史影像 / 三维展品”可切换。三维展品用于构型科普；不对应该节点型号的地方有说明。空间站展品复用第二章的完整模型。

## 交互

第二章保留电影式开场、实体/剖切/透视/爆炸、实验设施与生活区讲解、带碰撞检测的舱内漫游。舱内点击画面后可用 WASD 移动，Q/E 升降，拖动环视，Esc 释放鼠标；手机使用屏幕方向按钮。

第三章保留长征十号、昊龙、火箭拆解、内部剖视、发射分级、发动机与神舟返回舱展品。外部研制方案与教学动画不列为已完成的历史飞行成就。

隐藏章节停止申请动画帧并清除移动输入，恢复章节时继续操作。三维博物馆按需初始化；默认照片展区无需创建 WebGL 场景。减少动态效果偏好下展台不自动旋转。

## 网页嵌入

把 `index.html` 上传到网站静态资源目录后即可使用：

```html
<iframe src="/aerospace/index.html"
        title="中国航天探索馆"
        style="width:100%;height:850px;border:0"
        allow="fullscreen; autoplay"></iframe>
```

`#museum`、`#station`、`#rocket` 可直接进入相应章节。外部史料链接需要联网。

## 修改与重新构建

在本目录执行：

```sh
npm install
npm run build
npm run preview
```

Node.js 20 或更高版本。也可使用已安装的本机 Teardown 依赖。`build.mjs` 读取父目录空间站离线页、`assets/launch.html` 火箭离线快照及本目录源码，生成单文件 `index.html`，并同步工作目录中的 `中国航天探索馆_三章合一.html`。离线成品不需要安装 Node.js。

`history.js` 管理事件；`photos.json` 记录真实图片原始链接、拍摄对象、权属信息与原文件哈希；`assets/photos/` 保存压缩图片。图片按比例缩放并转为 WebP，未用生成式处理改写新闻影像。

## 验证与资料

`npm run verify` 验证离线运行、20 张图片解码、历史筛选、放大、三维拖动、空间站交互、火箭子展品、隐藏章节暂停和移动端宽度。先执行 `npx playwright install chromium`，或通过 `CHROME_PATH` 指定现有 Chrome。

`validation.json` 为交互报告，`source-validation.json` 为史料链接核对报告，`captures/` 为验收截图。`check-sources.mjs` 可重新检查史料可访问性；HTTP 成功本身不代替人工核对内容。

`照片与史料记录.md` 说明照片对应关系及模型边界；软件与字体许可在 `licenses/`，图像权属以 `photos.json` 记录为准。新闻照片没有因此变为开源或自有资产。
