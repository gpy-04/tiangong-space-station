# 中国航天探索馆

双击同目录的“中国航天探索馆_三章合一.html”即可打开，推荐使用 Chrome 或 Edge。历史图片、字体、地球纹理与三维展区已内嵌，可离线使用。

## 展馆内容

1. 历史博物馆：纵向图文时间线，直接向下滚动浏览 20 个中国航天历史节点，每项配一张真实图片。杭州与浙江的四项成就单独强调，可通过目录快速定位。
2. 天宫空间站：电影式开场、三舱外形、剖切、透视、爆炸拆解、实验设施、生活区与舱内自由漫游。
3. 火箭与发射：长征十号、昊龙、分级与发射演示，以及发动机和神舟座舱独立展品。

## 操作

- 顶部导航切换三章，右上角可全屏。
- 三维画面拖动旋转、滚轮缩放；各展区提供视角和拆解按钮。
- 舱内漫游先点击画面，WASD 移动，Q/E 升降，拖动环视，Esc 释放鼠标。手机使用屏幕方向按钮。
- 历史馆按时间顺序连续展示简短介绍与真实图片，无需逐项点击。点击图片可放大，Esc 关闭；页面不列图片出处。切到其他章节后返回，会保留阅读位置。

## 嵌入现有网站

将 HTML 文件上传到静态资源目录后，使用 iframe 嵌入；文件名可改为 index.html。

```html
<iframe src="/aerospace/index.html"
        title="中国航天探索馆"
        style="width:100%;height:850px;border:0"
        allow="fullscreen; autoplay"></iframe>
```

在文件地址末尾加 #museum、#station 或 #rocket 可直接进入对应章节。查阅外部史料需要联网。
