# 中国航天发展与 AI 结合课程汇报

共 29 页，以教师讲解和网页演示为主，按航天史导入、AI 与航天结合、空间站和火箭模型演示的课堂顺序组织。

- `index.html`：离线交互汇报，包含开场海报、逐页讲稿、目录和内嵌展馆。
- `aerospace-ai-course-report.pptx`：配套 PowerPoint 汇报文件。

AI 内容结合三体计算星座、祝融号自主避障和嫦娥六号智能采样等案例。空间站集中为 5 页，火箭与运输部分为 8 页。模型用于科普，公开方案与教学示意不等同于工程图纸。

在线入口：https://gpy-04.github.io/tiangong-space-station/course-report/

HTML 下载后可直接用现代浏览器打开，无需联网。网页中可进入空间站及火箭演示，再返回原汇报页。PPTX 可直接用于 PowerPoint 演示，内含逐页讲稿。
