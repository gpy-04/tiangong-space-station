# 天宫 · 中国空间站交互图鉴

新增整合版：[`exhibition/index.html`](exhibition/index.html)，依次包含历史博物馆、天宫空间站、火箭与发射。历史馆默认突出杭州与浙江，20 个事件均配真实照片或任务实拍，讲解默认折叠。操作与重新构建说明见 [`exhibition/README.md`](exhibition/README.md)。

双击 `index.html` 即可使用，资源已内嵌，运行时无需网络。

- 三舱、外壳、实验设施、生活区、可跳过的电影式开场。
- 实体、剖开、透视、爆炸图和带碰撞检测的舱内自由相机。
- 问天 5 处、梦天 8 处设施讲解及教学原理控件。
- 提供可编辑 GLB、Blender 工程与同一模型渲染的 1080p / 60 fps 导览。

详细操作见 [使用说明](使用说明.md)，公开报道和重建边界见 [来源与精度说明](来源与精度说明.md)。模型是科普重建，各连接尺寸不构成工程图纸。

## 下载与大文件

本仓库使用 Git LFS 保存 `.blend`、`.glb` 和 `.mp4`。克隆前安装 Git LFS，然后执行：

```sh
git lfs install
git clone <仓库地址>
git lfs pull
```

直接下载 GitHub 源码 ZIP 可能只包含大文件指针，请使用已打包的本地完整交付 ZIP 或 Git LFS 拉取完整模型。
